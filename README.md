# 五張撲克牌遊戲

## 專案簡介

本專案為「視窗程式設計（二）」上課練習作品，主題是五張撲克牌遊戲。  
玩家可以選擇出生背景、設定押注金額、進行發牌、換牌，最後由系統判斷牌型並依照賠率計算中獎金額。

本作品除了完成基本的發牌、換牌與判斷牌型功能外，也加入下注系統與出生背景設定，使遊戲流程更完整。

---

## 功能介紹

### 1. 發牌功能

按下「發牌」按鈕後，系統會隨機洗牌並發出五張撲克牌。  
牌面使用 PictureBox 顯示，圖片資源由專案 Resources 中的 `back` 與 `pic1` 到 `pic52` 提供。

### 2. 換牌功能

玩家可以點選想要換掉的牌，被選取的牌會翻成牌背。  
按下「換牌」後，系統會將被選取的牌替換成新的牌。

### 3. 判斷牌型

按下「判斷牌型」後，系統會根據五張牌判斷結果。  
目前可判斷的牌型包含：

- 皇家同花順
- 同花順
- 四條
- 葫蘆
- 同花
- 順子
- 三條
- 兩對
- 一對
- 無牌型

### 4. 下注功能

玩家可以在下注區輸入或選擇押注金額。  
系統會先扣除押注金額，最後依照牌型賠率計算中獎金額並加回總資金。

### 5. 出生背景設定

本作品加入創意功能「出生背景」，玩家可以選擇不同身份開始遊戲：

| 出生背景 | 初始資金 |
|---|---:|
| 富二代 | 1,000,000 |
| 凡人 | 100,000 |
| 窮人 | 10,000 |

遊戲開始下注後，出生背景會被鎖定，避免中途更改資金。

## 操作流程

1. 開啟程式。
2. 選擇出生背景。
3. 在「押注金額」中選擇或輸入金額。
4. 按下「押注」。
5. 按下「發牌」。
6. 點選想要換掉的牌。
7. 按下「換牌」。
8. 按下「判斷牌型」。
9. 系統顯示牌型、賠率、中獎金額與目前資金。
10. 若仍有資金，可重新下注進行下一局。

- C#
- Windows Forms App
- .NET Framework

1. 使用 Visual Studio 開啟專案。
2. 確認專案可以正常建置。
